## S5：分层阈值 + 真实数据验证

> **步骤 1：价值层 = 当月内按预测分排名，切四个分位区间。**
> 每月可打分商品按 pred_expected 从高到低排名转百分位：前 5% 是 A 层（rank≥0.95），
> 5%~20% 是 B，20%~50% 是 C，后 50% 是 D。**每月独立排，不跨月混排**——因为每月候选集合和量级不同。
>
> 用 2025-08 真实数据验证：该月 A 层门槛是 **pred_expected ≥ 579.54 元**；
> 「角钢」rank=1.0、pred=403.6 万 → A 层；「从此进出」标识牌 pred=31.13、rank=0.6327 → C 层。
> ```
> 商品名称          pred_expected   rk       value_layer
> 角钢              4036017.5      1.000000   A
> "从此进出"标识牌     31.129623     0.632717   C
> ```

**点评**：给出真实门槛值 579.54，并用两行真实数据演示"高分进 A、低分进 C"，
用户能立刻拿 layers.csv 自己核对 rank 和层的对应关系。

## S6：加权公式代入前两行手算（集中度 proxy）

> 公式：proxy = Σ(w_i · s_i) / Σ(w_i)，w_i = 预测分，s_i = 供应商集中度。
> 用 2025-08 清单前两行演示：
> ```
> 角钢       w=4,036,017.5  s=0.544613
> 10kV电缆   w=3,415,231.5  s=0.168898
> 前两行加权 = (4,036,017.5×0.544613 + 3,415,231.5×0.168898) / (4,036,017.5+3,415,231.5)
>            = (2,197,988 + 576,904) / 7,451,249 ≈ 0.3724
> ```
> 300 行全部算完，proxy = **0.4508**，与 allocation_stats.csv 分毫不差。

**点评**：这就是 recompute_templates.py 里模板 4 的"人话版"。先把公式写出来，
再代入真实的前两行一步一步乘、加、除，最后给全量结果并和落盘值比对。
（agent 实际讲解时，可直接运行模板 4，它会自己打印这个"前2行加权演示"。）

## 它怎么诚实讲"约束没触发"（不掩饰，反而讲成洞察）

> proxy 离 0.99 上限很远，while 循环一次都没触发（n_concentration_drop=0）。
> 这不是"约束没用"，而是数据本身高价值商品大多多家供货——清单 300 个里只有 47 个独家（15.7%），
> 而面板整体 95.8% 是独家。**清单切片和面板整体是两个世界。**
> 因此报告不下任何供应商层面的强结论，等拿到供应商身份数据再重设计。

**点评**：遇到"设计的约束根本没生效"，不粉饰成"约束保障了多样性"，
而是追因到"为什么没生效"（高价值商品≠独家商品），并诚实地收缩结论边界。
**诚实 > 漂亮**，这是白盒讲解的底色。
